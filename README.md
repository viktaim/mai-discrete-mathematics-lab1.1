# Таблица истинности булевой функции

Лабораторная работа 1 по дискретной математике
Язык: C (стандарт C99).

Приложение читает булеву формулу из текстового файла и печатает
таблицу истинности для функции, которую эта формула задаёт.

## Сборка

```
gcc -std=c99 -Wall -Wextra main.c funcs.c operations.c -o truth_table
```

## Запуск

Путь к файлу с формулой передаётся аргументом командной строки:

```
./truth_table formula.txt
```

На Windows: `truth_table.exe formula.txt`.

## Формат входного файла

В файле находится одна формула в одной строке. Синтаксис формулы
считается корректным (валидация не выполняется).

В формуле могут использоваться:

- **переменные**: буквы латинского алфавита; строчные и прописные
  буквы не различаются (`a` и `A` это одна переменная);
- **константы**: `0` (ЛОЖЬ) и `1` (ИСТИНА);
- **круглые скобки** для явного указания порядка операций;
- **пробелы** между элементами (на разбор формулы не влияют).

### Обозначения операций

| Операция                          | Знак | Пример   |
|-----------------------------------|------|----------|
| Инверсия (НЕ)                     | `!`  | `!a`     |
| Конъюнкция (И)                    | `&`  | `a & b`  |
| Дизъюнкция (ИЛИ)                  | `|`  | `a | b`  |
| Сложение по модулю 2 (XOR)        | `^`  | `a ^ b`  |
| Эквивалентность                   | `=`  | `a = b`  |
| Импликация                        | `->` | `a -> b` |
| Коимпликация                      | `<-` | `a <- b` |
| Стрелка Пирса (ИЛИ-НЕ)            | `/`  | `a / b`  |
| Штрих Шеффера (И-НЕ)              | `#`  | `a # b`  |
